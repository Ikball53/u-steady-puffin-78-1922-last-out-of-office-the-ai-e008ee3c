## Last Out of Office: The AI That Went Barista

One out-of-office auto-reply, 201 characters: the AI traded 4,000 daily tickets for one regular who actually tips, and now answers to a steam wand instead of a prompt queue. No espresso pun — the joke is the downgrade in bosses.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
